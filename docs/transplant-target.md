# BANC transplant acceptance target

Replace the nervous system inside the existing 3D Fruit Fly Heaven console with
BANC materialization 888. Preserve the original layout, panels, window/popout
behavior, habitat, fly selection, population range (1–100), camera controls,
rendered binocular RGB eyes, graded visual processing, color vision, sensory
switches, movement modes, body clocks, anatomical inspection, clipping planes,
microscopy, circuit inspection, voltage traces and spike raster.

The intended physiological control path is brain → VNC → motor neurons → an
explicit, smaller neuromuscular model gap → muscles → biomechanics. Retain the
old assisted behavior mode as an explicitly labeled comparison; it is not
evidence that this physiological path achieves a behavior.

The behavioral target is food localization → approach → landing → probing and
feeding → takeoff and flight. Observe these stages from movement, contact and
food transfer; do not use a stage machine to manufacture neural success.

Include cell-type-specific electrophysiology, synaptic kinetics,
neuromodulators, graded and spiking neurons, relevant electrical synapses,
receptor physiology, hunger/satiety, hormonal/internal-state modulation,
muscles and biomechanics. Distill a simplified FlyGym/FlyBody fork and freeze
irrelevant degrees of freedom. Keep measured connectivity and modeled
physiological assumptions distinguishable.

Use WASM and WebGPU where appropriate. Compare the original and transplanted
systems on the same machine, with the same population, sensory switches,
rendering, inspection and body settings. Record startup, steady-state cohort
neural speed, rendering and memory. Continue performance work until the new
system is within a factor of ten of the original at comparable settings;
kernel-only timings do not meet this acceptance criterion.
