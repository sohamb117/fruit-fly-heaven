# Experimental target

Read `GOAL.md` before working on the connectome–body study. Recheck its relevant
experiment before choosing a milestone, changing the protocol, compiling or
launching a study, or reporting progress. This is the user's authoritative target;
`connectome_body/PAPER_PLAN.md` is an archived copy.

Current work covers the ten experiments, the complete connectome × body matrix,
the adapter families, five plasticity regimes, and additional drone, temporal and
diagnostic-to-control benchmarks in `GOAL.md`. The earlier
BANC-only FlyBody adapter campaign is historical work. Repeating it does not
complete an expanded-study milestone.

The current implementation is `connectome_body/connectome_body/compatibility/`.
Use `connectome_body/PAPER_README.md` for commands and `PAPER_PROTOCOL.md` for
measurement details, with `GOAL.md` controlling scope. Report implementation
checks, input readiness, and completed scientific trials separately.
