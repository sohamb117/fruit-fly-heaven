# Current flight diagnosis

The event-to-muscle route has passed a bounded mechanical positive control and its first [actual BANC/native-body comparison](../flight-event-live/comparison-final/INTERPRETATION.md). Stable flight remains unvalidated: the event arm achieved 174 ms of qualifying flight versus 166 ms, then failed from excessive rotation earlier (392 ms versus 480 ms). The default baseline exactly reproduced its prior physical digest and motor packets. Training is not the next acceptance test.

| Boundary | Completed evidence | What remains unresolved |
|---|---|---|
| Events → muscles → wing mechanics | In the [four-arm native assay](run-001/README.md), the frozen synthetic feedback controller held maximum tilt to 7.20° for 1.5 s through the event path; fixed trim reached 43.52°. The causal native-only control reached 6.64°. No root force or pose correction occurred after release. [Muscle characterization](../flight-motor-event-observer/characterization/README.md) and [phase probes](../wing-event-phase/README.md) retain event timing and expose distinct excitation, activation, fatigue and force. | This uses prepared flight, synthetic commands and a classical controller with explicit body-state feedback. It does not validate BANC control, cold takeoff, landing, biological muscle constants, or the absence of servo clipping. The recorded high DLM activity still nearly saturates the event excitation prior. |
| Incoming synaptic drive → DLM spikes | The [frozen-conductance replay](../flight-dlm-published-model/reference/replay/run-numerical-001/README.md) gave 107.22 Hz mean raw firing with the generic motor profile versus 38.89 Hz raw crossings with the published ionic reference in the same (100,280] ms window. All ten ionic cells remained active; the zero-input control was silent. The [equation reference](../flight-dlm-published-model/reference/README.md) separately matched the actual author implementation. | This was a 300 ms open-loop conductance replay, not a reconnected BANC replacement or a steady-state physiological fit. Its separately pinned numerical gate retained a strict failure and allowed small voltage-only differences; it was not wholly bit exact. Actual cell-profile integration, backend/event timing checks, and unchanged-graph behavior remain unvalidated. DVM and steering profiles are separate questions. |
| Body rotation → sensory currents | The [signed observability audit](../flight-sensory-observability/INTERPRETATION.md) found identical immediate requested sensory vectors under positive/negative angular-velocity pairs at fixed pose. The current rotation mapper still consumes angular-speed magnitude while preserving organ/side identity. | The 27 motor gains cannot reconstruct sign information removed by the encoder. Directional receptive fields, local strain and timing remain unresolved modeling boundaries; anatomical group names do not establish preferred axes or signs. Indirect information through evolving movement and contacts is not excluded. |

The observability audit predates the [50-cell proximal hair-plate exclusion](../flight-proximal-sensory-repair/README.md). That correction removed an unsupported whole-body-speed/yaw fallback and improved one recorded trial to 166 ms of qualifying flight before a 480 ms rotation failure. It did not add signed rotation feedback or reduce DLM firing. The audit's historical fallback counts therefore describe its pinned encoder, while the magnitude-only rotation limitation remains in the current `banc-ground-sense.js` formula.

Before renewed body-level training:

1. Retain the completed opt-in preservation/causality checks and first actual BANC comparison as the baseline. Native grounded takeoff occurred, but sustained flight and landing still failed. Future model comparisons should keep the same seed, unchanged remaining parameters and real motor/body records; no synthetic controller or rate inverse belongs in those BANC comparisons.
2. Implement and independently validate the [opt-in DLM ionic profile](../flight-dlm-published-model/runtime-integration-plan.md) before testing it in the recurrent network. Preserve real BANC inputs and graph edges; do not add the paper's tonic current or assumed electrical pairs. Retain exact event-time contracts through the effector.
3. Resolve or explicitly bound the directional-feedback limitation using anatomical grouping and controlled neural/physical response tests. Do not assign receptor axes from names or ask an optimizer over motor gains to compensate for missing measurements.

These are distinct changes to test separately. Successful training must ultimately demonstrate takeoff, maintained flight and landing with the actual neural loop; passing the prepared synthetic control is only evidence that this motor/body route can support stabilized motion under the stated conditions.
